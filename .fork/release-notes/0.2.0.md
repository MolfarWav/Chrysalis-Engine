# 🎭 Molfar Vertep 0.2.0

Updates you can actually find, a chronicle keeper for your roleplay worlds, and a new name. Your apps, chats and settings are kept.

## ✨ What's new

### 🔄 Updates in one place
A new **Updates** button in the top bar, next to your account, lights up when something is newer. One panel lists Molfar Vertep itself (for admins) and every app installed from a repository:
- each row shows **current → new version**, a **Changes** link to what is different, and an **Update** button;
- **Update all** goes through your apps one by one and stops at the first that needs your decision;
- if your own edits overlap with an update, you choose, as before: keep yours, take the update, or let the agent merge them.

Checks run once when Molfar Vertep starts, then whenever you press **Check now**. Before, updates were only reachable from the launcher's app page, and not at all from inside an open app.

The **Molfar Vertep logo** in the top bar now takes you back to the start screen from any tab.

### 📜 Litopys: a chronicle keeper for your roleplay worlds (Roleplay 4.19)
**Archivarius is now Litopys**, and it ships with Roleplay instead of being a separate plugin. While you play, it reads each chat and keeps:
- **world facts**: who is who, places, rules of the world, in the story's own language;
- **a chronicle** of what happened, and a **running recap** of the story so far;
- a **curator** that proposes clean-ups for you to approve: merge duplicates, reword vague facts (a name instead of "he", a rumor marked as a rumor), retire what the story has overturned. When unsure it keeps a fact, and nothing is removed just for being old.

It is careful about what counts as a fact: a character's claim is kept as that character's claim, not as truth about the world, and one-scene details (mood, weather, time of day) are left out.

Its prompts ship as defaults: if you never edited them, you get every improvement automatically; if you did, **Restore default prompts** brings the default back. Your Archivarius data is read until Litopys first saves, so nothing is lost, and an old Archivarius copy left in your plugins stops running so the two never both call the model.

### 🧠 Chat memory understands Ukrainian and Russian (Roleplay 4.19)
Memories now surface when you write in Cyrillic: recall matches word forms (stems), skips stop words, handles the typographic apostrophe (’) and gives rarer words more weight. Before, only Latin words of four or more letters could match, so Ukrainian and Russian memories never came back by text.

### 🏡 Roleplay now comes from Molfar Vertep's own fork
Roleplay installs and updates from [MolfarWav/Molfar.Vertep-Roleplay](https://github.com/MolfarWav/Molfar.Vertep-Roleplay). An existing install switches its update source on the next start; your code and data stay as they are, and the next update merges cleanly.

### 🪪 The new name: Molfar Vertep
The interface (all 13 languages), page titles, console messages and README now say Molfar Vertep. Existing installs keep their data: internal names (the `chrysalis` command, data folders, `CHRYSALIS_*` settings, download file names) stay as they were.

## 🛠️ Fixes
- **App updates work again.** Since 0.1.0 every app update was refused as "needs a newer engine": apps state their engine needs in Chrysalis numbers (`>=1.0.0`), and they were checked against Molfar Vertep's own 0.1.0. They are now checked against the app contract this engine keeps (1.0.2).

## Other changes
- Roleplay 4.19: plugin panels gain dropdowns, a grouped model picker, hints and an Advanced section; the memory model setting uses the same searchable picker; optional per-level heading colors, the Neon Tokyo Night theme and two neon heading styles; a detailed file map (`docs/ARCHITECTURE.md`) and app skills for the agent.
- A plugin manifest can say `"replaces": ["<id>"]`: the plugin it names stays on disk but never runs.
- Update checks follow MolfarWav/Molfar.Vertep releases.
- Releases are built automatically from a `vX.Y.Z` tag, with downloads for Windows, macOS, Linux and Android.

## ⬇️ How to get it
- **Running from source:** pull the tag `v0.2.0` (or restart with your launcher).
- **Downloads** below: `Chrysalis-0.2.0-<system>` (the file names stay as before so self-update keeps working). The Android APK is debug-signed and cannot update an installed copy.
- **Roleplay 4.19** is an app update: after updating Molfar Vertep, open **Updates** in the top bar and update Roleplay.
