Molfar Vertep 0.2.0. Your apps, chats and settings are kept.

## Highlights
- **Updates in one place.** A new Updates button in the top bar shows what is newer: Molfar Vertep itself (for admins) and every app installed from a repository. Each row shows current → new version, a link to the changes and an Update button; "Update all" goes through them one by one. If your own edits overlap with an update, you pick what happens, as before: keep yours, take the update, or let the agent merge. The Molfar Vertep logo now takes you back to the start screen.
- **The new name: Molfar Vertep**, in all 13 interface languages. Existing installs keep their data.
- **Roleplay now comes from Molfar Vertep's own fork** ([MolfarWav/Molfar.Vertep-Roleplay](https://github.com/MolfarWav/Molfar.Vertep-Roleplay)). An existing install switches to it on the next start; your code and data stay.
- **Archivarius is now Litopys** and ships with Roleplay.
- **Fixed:** since 0.1.0 every app update was refused as "needs a newer engine".

The full list is in [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md).
