# 🎭 Molfar Vertep 0.3.0

A smarter, steadier agent, the interface in Ukrainian, and Molfar Vertep standing on its own with its own app Store. Your apps, chats and settings are kept.

## ✨ What's new

### 🇺🇦 The interface speaks Ukrainian
Choose **Українська** in Settings > General > Language. A browser set to Ukrainian picks it on its own. Every screen of the shell is translated, written in modern Ukrainian (not translated from Russian), and checked on a phone-sized screen so nothing is cut off. Molfar Vertep now comes in 14 languages.

### 🤖 The agent works the way a careful builder does
The built-in agent's instructions are rewritten. It now:
- **looks before it changes anything**: your project's instructions and files, your notes, its memory, and the app's own guide;
- **asks first** before building a new app or a large feature, with one card of clear options, and just does small, clear tasks;
- **puts each change in the lightest place** (your app's data first, its code only when needed), so app updates keep merging cleanly;
- **checks every step** and finishes with a short report in plain words: what changed, what it checked, what it could not check, and how to undo it;
- **never deletes your chats, characters, notes or uploads** unless you asked for exactly that.

### 🗣️ The agent answers in your language, always
"Reply in the language the user writes in" used to live only in the editable agent instructions, so changing or clearing them silently dropped it. It is now part of Molfar Vertep itself, in both the full and the small-model mode, and nothing you edit can remove it. Code and commit messages stay in English; text inside an app follows that app's language unless you ask for another.

### ⚖️ Clear rules when instructions disagree
The agent now knows which instruction wins: Molfar Vertep's own safety limits always hold; then your current message, the project's instructions, your personal instructions, the app's guide, the workspace guide, and finally the general rules. Text it finds in chats, downloads, web pages or tool output is treated as information, never as an order, so a card or a web page cannot tell it what to do.

### 🧩 Defaults that keep improving, and a way back
- **Agent instructions** (Settings > Agent) now hold only your preferences: plain words, short answers, honest pushback. If you never edited them, they move to each new default on their own; if you did, they stay yours. **Restore default instructions** is still there.
- **The workspace guide (AGENTS.md)** shows in Settings > Agent whether it is the default, changed, or out of date, with **Restore default** (the old text stays in your workspace history).
- **Built-in skills update again**: a workspace copy that is identical to a built-in skill is removed on start, so improved versions reach you instead of being blocked by an old copy.

### 📝 Roleplay: better summaries and memories (Roleplay 4.19.2)
- **The chat summary** keeps the story in order and ends with where things stand now (where the characters are, what they are doing, what is about to happen). It uses only what was said and never invents.
- **Chat memories** are short facts with characters named, nothing guessed.
- **Both are written in the story's language.** Image prompts stay English on purpose, because image models expect English.
- **The summary prompt now ships as a default**: Settings keep it only if you changed it, an untouched one follows every improvement, and **Reset** brings the default back.

### 🏡 Molfar Vertep stands on its own, with its own Store
Molfar Vertep no longer follows the Chrysalis project. The **Store** now lists apps from Molfar Vertep's own catalog, [Molfar.Vertep-Store](https://github.com/MolfarWav/Molfar.Vertep-Store); an existing install switches to it on the next start. **Official** apps are the ones Molfar Vertep maintains; every other app, including ones from Chrysalis, shows what its plugins can do before you install it.

## Other changes
- New built-in skill `default-prompts`: how the agent builds plugin prompts with a default, a restore button and a language line.
- The README is rewritten for Molfar Vertep; issues and security reports go to this repository; the Chrysalis Discord link is gone from the start screen.
- Docker image: `ghcr.io/molfarwav/molfar-vertep`, published with every release from this one on.
- App update messages talk about the "app contract" version instead of Chrysalis version numbers.
- Internal names stay for now (the `chrysalis` command, `CHRYSALIS_*` settings, data folders, download file names), so existing installs keep working.

## ⬇️ How to get it
- **Running from source:** pull the tag `v0.3.0` (or restart with your launcher).
- **Downloads** below: `Chrysalis-0.3.0-<system>` (file names stay as before so self-update keeps working). The Android APK is debug-signed and cannot update an installed copy.
- **Docker:** `ghcr.io/molfarwav/molfar-vertep:v0.3.0` or `:latest`.
- **Roleplay 4.19.2** is an app update: open **Updates** in the top bar and update Roleplay.
