# 🎭 Molfar Vertep 0.3.1

A one-file launcher for Windows, and a fix for app updates that could freeze Molfar Vertep. Your apps, chats and settings are kept.

## ✨ What's new

### 🚀 Start Molfar Vertep with one file
`Molfar-Vertep.bat`, in the repository root, runs Molfar Vertep from source on Windows. Put it in any folder and double-click it:
- it installs **Git and Bun** if they are missing, and says so in the window while it does;
- it **downloads Molfar Vertep next to itself** the first time;
- when a **new release** is out, it asks before installing it (`Molfar-Vertep.bat dev` follows work in progress instead);
- it never overwrites your own changes to Molfar Vertep's files;
- it reinstalls and rebuilds **only when something changed**, so a normal start is quick;
- it offers a **desktop shortcut** once, with the Molfar Vertep icon;
- it **opens Molfar Vertep in your browser** by itself.

It works from any folder, including names with spaces or in Ukrainian or any other language. A copy kept somewhere else still finds your Molfar Vertep, and switching to a version that does not ship the launcher keeps it in place.

## 🛠️ Fixes
- **App updates no longer freeze Molfar Vertep.** On Windows, an update could write all its files and then wait forever while deleting its temporary download, because another program (usually an antivirus scanning the fresh files) held one of them. Nothing answered until a restart. Temporary folders are now removed in the background, with retries, and a half-finished update is cleaned up by the next one. If an update froze for you before: restart Molfar Vertep; the app is already updated, and if it reports a conflict, ask the agent to fix it from inside the app.
- **Improved built-in skills reach you again.** A workspace copy of a built-in skill that you never edited used to block the improved version once the built-in had changed. Molfar Vertep now recognises copies of every earlier version and removes them on start.

## Other changes
- Molfar Vertep opens the browser for a copy run from source when its launcher started it (`openBrowser` in config.yaml still decides).
- The old launchers in `.fork/` are replaced; `.fork/start-chrysalis.bat` now just starts the new one.

## ⬇️ How to get it
- **Launcher users:** run `Molfar-Vertep.bat` and answer **Y** to "Update to release v0.3.1".
- **Running from source otherwise:** pull the tag `v0.3.1`.
- **Downloads** below: `Chrysalis-0.3.1-<system>` (file names stay as before so self-update keeps working). The Android APK is debug-signed and cannot update an installed copy.
- **Docker:** `ghcr.io/molfarwav/molfar-vertep:v0.3.1` or `:latest`.
