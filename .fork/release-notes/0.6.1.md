# 🪟 Molfar Vertep 0.6.1

Roleplay's sections open over the page again, and apps fix their own missing packages. Your apps, chats and settings are kept.

## ✨ What's new

### 🪟 Roleplay 4.21.1: sections over the page again (through app updates)
Open **Updates** in the top bar to install Roleplay 4.21.1. On a computer, Characters, Personas, Lorebooks, Presets, Settings and the other sections open as a drawer over the page again, as they did before 4.20.0: Home, Chats or your open chat stay underneath, and a reply that is still being written keeps going. Press Esc, click beside the drawer or click the section again to close it. On phones nothing changes: a section is its own page, and a drawer over an open chat.

### 🧙 Molfar's app changes can become everyone's default
When Molfar improves an official app such as Roleplay for you, that change can now ship to every user. A new built-in skill, **publishable-changes**, tells Molfar how to write such changes: defaults in the code, never your personal data, and a commit message that says what you get. Start a commit message with `local:` for a tweak you want to keep to yourself. The maintainers publish the rest with `scripts/publish-app.ts`, which looks only at the app's code: never its `data/` folder and never Molfar's memory of the app.

## 🛠️ Fixes
- **An app no longer stays broken when an update's package install fails.** Roleplay 4.20.0 added a font package; if installing it failed during the update (offline, a Bun error), the app would not build ("Could not resolve"), and nothing tried again. Now opening the app installs any package its `package.json` lists but its `node_modules` lacks (at most once every 10 minutes per app), and every start does the same.

## Other changes
- For maintainers: `scripts/publish-app.ts` (`list`, `diff`, `apply --into <clone>`) lists an app's code changes since its last update with warnings (secrets, local paths, the user's name, lockfiles) and the workspace's commits, and carries chosen files into a clone of the app's repository with a three-way merge.

## ⬇️ How to get it
- **Launcher users:** run `Molfar-Vertep.bat` and answer **Y** to "Update to release v0.6.1". Then open **Updates** in the top bar for Roleplay 4.21.1.
- **Running from source otherwise:** pull the tag `v0.6.1`.
- **Downloads** below: `Chrysalis-0.6.1-<system>` (file names stay as before so self-update keeps working). The Android APK is debug-signed and cannot update an installed copy.
- **Docker:** `ghcr.io/molfarwav/molfar-vertep:v0.6.1` or `:latest`.
